Project data key `definitions`(`data`, schema `object`, default `{}`)는 정의 식별자마다 `{name, account, plugin, role, cwd}`를 담는다. `role`은 core role 식별자이며 정의 식별자와 같다. `plugin`은 정의할 때의 setting `terminalPlugin`(`settings`에 선언, default `terminal`) 값이므로 코드에 plugin 이름이 literal로 없다. `program`과 `args`는 저장하지 않으며, 읽을 때 계정(`cli`, `args`)에서 얻는다. 명령 `agents.definition.define {group, id, name, account, cwd, text, ko, files}`는 group과 membership, 계정이 정의되었는지, `name`이 1자 이상 40자 이하인지, `cwd`가 절대 경로인지 검사한 뒤 `core.role.define {id, text, ko, files}`을 실행하고, 정의를 저장하며 식별자를 group의 members에 더한다. 명령 `agents.definition.remove {group, id}`는 `core.role.remove {id}`을 실행하고 정의와 member를 지운다. `agents.account.remove`는 정의가 쓰는 계정을 거부한다. Members는 식별자만 담는다. Page는 각 member의 text, 한국어 text와 files를 status `core.roles`에서 읽고, `core.roles`가 정의하지 않은 member는 정의되지 않은 것으로 보인다.
